upgrade

1. Update to v0.6.21. 更新到 v0.6.2

For an existing Homebrew installation:已有 Homebrew 安装：

brew update
brew upgrade catoncat/sherlog/sherlog
shlog --version

Or replace an existing installer-managed binary:或更新通过安装脚本安装的 CLI：

curl -fsSL https://github.com/catoncat/sherlog/releases/latest/download/install.sh | SHERLOG_FORCE=1 sh
shlog --version

This release supports Apple Silicon macOS and Linux x64 GNU. The optional agent skill is installed separately.本版支持 Apple Silicon macOS 和 Linux x64 GNU。可选的 agent skill 单独安装。

2. Recover your Codex history2. 恢复 Codex 历史索引

shlog sync --source codex

Keep your usual --root, --cwd, and --db options when working with a custom scope. This sync automatically replays files indexed by older Codex parsing rules. You do not need to delete the database. Later unchanged files are skipped as usual.使用自定义范围时，保留原来的 --root、--cwd 和 --db。此次同步会自动重放旧 Codex 解析规则处理过的文件，不需要删除数据库；后续无变化的文件仍照常跳过。

Indexes from 0.4.x are migrated with a backup. A normal 0.5.x refresh updates projections in place. After upgrading, use the new CLI for all index writes.0.4.x 索引迁移会保留备份；0.5.x 的普通刷新直接更新投影。升级后，统一使用新 CLI 写索引。

3. Include archived history when needed3. 按需恢复归档历史

shlog sync --source codex --root /path/to/archived_sessions

Use the directory that contains your archived plain JSONL files, and keep that --root when searching. Default sync only scans the default active directory. Cold-root registration protects existing projections from pruning; compressed Codex cold files are not reindexed.替换为存放归档 plain JSONL 的目录，查询时也保留该 --root。默认 sync 只扫描默认活动目录；登记 cold root 只保护已有投影不被清理，压缩 Codex cold 文件不会重新索引。

Search, then execute the returned evidence read. Paginated continuations have separate sessionRef values.搜索后执行返回的证据读取命令。分页续段各自使用独立的 sessionRef。
